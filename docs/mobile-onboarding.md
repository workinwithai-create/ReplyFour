# Mobile onboarding

1. Open the desk in Safari or Chrome, not an in-app browser.
2. First-run dialog explains call, reply, punch list, and Forge Pass bounce.
3. Got it stores `replyfour-onboard=1` and stays dismissed.
4. Dock buttons are at least 44px and wrap on a phone width.
5. In-app user agents show the Safari/Chrome warning.
6. Bounce without a Forge Pass reopens the dialog and does not download.

Physical iPhone sign-off is still required before this row can be Met.
